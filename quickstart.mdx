## Get an API key

Go to [voicemark.dev/signup](https://voicemark.dev/signup) and create an account. Your API key will be in the format `vmk_live_<32hex>`.

<Warning>
  Keep your API key secret. It is a Bearer token — anyone who holds it can call the API under your account. Never expose it in client-side code in production.
</Warning>

## Your first verification

```ts
import { VoiceMark, recordVoice } from "voicemark-js";

const vm = new VoiceMark({ apiKey: "vmk_live_..." });

// 1. Get a challenge phrase
const { phrase, challenge_id } = await vm.challenge();
showToUser(phrase); // "If you can wait and not be tired by waiting,"

// 2. Record the user speaking the phrase
const { result, stop } = await recordVoice({
  onLevelUpdate: (rms) => drawWaveform(rms),
});
// ... user speaks ...
const { blob } = await result;

// 3. Verify — returns ephemeral token (60s TTL)
const { token, authorized } = await vm.verify(blob, {
  challengeId: challenge_id,
});

console.log(authorized);  // true
// token: "eyJhbGci..."   — ephemeral JWT, 60s TTL

// 4. Gate a privileged action
const { permitted } = await vm.policy(token, "payment.create");
if (!permitted) return showError("Voice verification required.");

// proceed with the action...

// 5. Log the audit receipt
await vm.receipt(token, "payment.create", "success", {
  amount: 5000,
  currency: "GBP",
});
```

```html
  // same API as above

```
